#  Airbnb Seattle Data Analysis

##  Project Overview

This project analyzes Airbnb listings in **Seattle, Washington**, using data on property listings, guest reviews, availability, and pricing.

The goal of the project is to explore the Seattle Airbnb market, identify patterns in listing characteristics and pricing, and uncover insights that can help understand **property performance, customer reviews, availability, and host behavior**.

The analysis was developed as a **Tableau data visualization project**, using structured Airbnb data to create meaningful dashboards and uncover business insights.

---

##  Project Objectives

The project aims to answer questions such as:

- What does the Airbnb market in Seattle look like?
- Which neighborhoods have the highest concentration of listings?
- How do property types and room types vary across the market?
- What factors influence Airbnb pricing?
- Which listings and neighborhoods have higher review activity?
- How does availability vary throughout the year?
- What relationship exists between price, availability, and property characteristics?
- How do guest ratings vary across Airbnb listings?
- What insights can hosts use to better understand the market?

---

##  Dataset

The Excel workbook contains three main datasets:

### 1. Listings

Contains information about Airbnb properties and hosts, including:

- Listing ID
- Property name
- Host information
- Neighborhood
- Property type
- Room type
- Number of guests accommodated
- Bedrooms and bathrooms
- Beds
- Amenities
- Price
- Cleaning fee
- Security deposit
- Minimum and maximum nights
- Availability
- Number of reviews
- Review scores
- Host status
- Cancellation policy
- Geographic coordinates

### 2. Reviews

Contains guest review information, including:

- Listing ID
- Review ID
- Review date
- Reviewer ID
- Reviewer name
- Review comments

This dataset can be used to examine **review activity and guest feedback**.

### 3. Calendar

Contains daily availability and pricing information for listings, including:

- Listing ID
- Date
- Availability status
- Daily price

This dataset makes it possible to investigate **seasonality, pricing patterns, and property availability**.
