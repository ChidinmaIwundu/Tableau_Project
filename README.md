# Tableau_Project
Seattle Airbnb Listings — Tableau Dashboard Project

A geospatial and pricing analysis of Seattle Airbnb listings, built in Tableau from a multi-sheet Excel dataset covering listings, guest reviews, and daily calendar availability.

Overview

This project explores Airbnb's Seattle market — where listings are concentrated, how price varies by neighbourhood and room type, and how availability and guest reviews behave over time. The Tableau workbook uses zip code and latitude/longitude fields to build interactive maps alongside neighbourhood- and room-type-level breakdowns.

Aim
To visualize this data in Tableau

Skills Demonstrated
Working with large, multi-sheet relational datasets and their format limitations
Geospatial visualization and troubleshooting geocoding in Tableau
Dashboard design for exploratory, multi-dimensional data (location, price, time, reviews)
